# Glossaire de la traduction française

pas dans la place d'une liste, garder le même début (ex. CEINT. CHAMPION).

FLEE = FUIR · CAMELEON COLOR = PEAU CAMÉLÉON · ITEM / TRAP / RUIN SEARCH = RADAR À OBJETS / À PIÈGES /
À RUINES · [SEA OTTER] / AIRPLANE (飛行艇) = HYDRAVION · COMMUNICATION (entre consoles) = LIAISON CÂBLE ·
rire フフフ : Eugene « HM HM HM… », Gre « HÉ HÉ HÉ… »
Pièces de Cyframe (noms en lettres normales) : PYRO- / CRYO- / FOUDRO- + MAIN / LAME / CART, BALLE SPÉC.,
JET, MAIN, MARTEAU… suivis de NV1..NV5.
Libellés d'écran (sur place, longueur limitée) : PV/PE/PT, NV, SUIV, FOR/VIT/DEX/AGI/VTS/CHA, ARME,
TÊTE, HAUT, PIED, ACCESS., EMPL1-5, TECHN1-5, FONDS, DETTE (DÛ dans l'écran de remboursement).
